# 命名规范

命名是代码可读性的一半。好的命名能让人一眼看懂意图。

## 文件命名

- 组件文件使用大驼峰：UserProfile.tsx
- 工具文件使用小驼峰：formatDate.ts
- 目录使用小写中划线：user-profile

## 变量与函数

- 变量使用小驼峰：userName
- 布尔变量加上 is / has / can 前缀：isVisible
- 函数使用动词开头：getUser、validateForm

## 组件命名

- 组件名使用大驼峰，且具描述性：SearchInput
- 避免缩写歧义：用 UserCard 而不是 UCard

## 常量命名

- 常量使用全大写下划线：MAX_RETRY_COUNT
- 枚举成员使用大驼峰：Status.Active

## CSS 类名

- 推荐使用 BEM：block__element--modifier
- 或语义化、带前缀，避免全局污染：cnki-btn--primary
